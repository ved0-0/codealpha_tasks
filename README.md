# CodeAlpha Python Tasks

This repository contains the Python projects completed as part of my CodeAlpha internship/tasks.

## Tasks

### Task 1 - Hangman Game
A simple text-based Hangman game where the player guesses a randomly selected word one letter at a time.

**Concepts used:**
- Lists
- Strings
- Random module
- Loops
- If-else conditions
- User input

### Task 2 - Stock Portfolio Tracker
A simple stock portfolio tracker that calculates the total investment based on predefined stock prices and the number of shares entered by the user.

**Concepts used:**
- Dictionaries
- Lists
- Loops
- Basic arithmetic
- User input and output
- Conditional statements


### Task 3 - Basic Chatbot
A simple rule-based chatbot that responds to predefined user messages such as "hello", "how are you", and "bye".

**Concepts used:**
- Functions
- If-elif-else
- Loops
- Strings
- User input and output
